# Chai Discovery

> Chai Discovery builds frontier AI to predict and reprogram the interactions between biochemical molecules. Its flagship Chai-1 is a multi-modal foundation model for biomolecular structure prediction (proteins, small molecules, DNA, RNA, glycans and complexes), and Chai-2 generates de novo antibodies directly from target epitopes. Chai-1 is available as an open-source Python package (Apache 2.0) and as a hosted commercial server.

## Products
- [Chai-1 (chai-lab)](https://github.com/chaidiscovery/chai-lab): SOTA model for biomolecular structure prediction; open-source Python package + weights (Apache 2.0).
- [Chai Design / hosted server](https://lab.chaidiscovery.com): Commercial hosted platform to run predictions without local GPU infrastructure.
- [Chai-2](https://www.chaidiscovery.com/news/chai-2-mab): De novo antibody design system that generates antibodies from target epitopes.

## Packages
- [chai_lab on PyPI](https://pypi.org/project/chai_lab/): pip install chai_lab==0.6.1 (Python 3.10+, Linux, CUDA GPU).

## CLI
- `chai-lab fold input.fasta output_folder` — predict a structure from a FASTA file. Flags: --use-msa-server, --use-templates-server, --msa-server-url.
